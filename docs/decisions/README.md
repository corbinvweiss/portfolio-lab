# Decision records

One short file per change to a stage contract or an invariant listed in `CLAUDE.md`.
Specs are not rewritten after the fact; the affected spec section gets a one-line
"superseded by decisions/NNNN" note instead.

File name: `NNNN-short-title.md`, numbered in order of adoption.

Template:

```
# NNNN. Title

Date: YYYY-MM-DD · Week: N · Status: accepted | superseded by NNNN

## Context
What was true before and why it stopped being adequate.

## Decision
The new contract or invariant, stated precisely enough to test.

## Consequences
What breaks, what tests change, what later weeks must respect.
```
